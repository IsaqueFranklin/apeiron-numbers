# Architecture and scientific basis

For a parameter-by-parameter command guide and a fuller derivation of the waiting-time and bit rules, see [theory-and-run-guide.md](theory-and-run-guide.md).

## Purpose and source

The model produces a sequence of physical waiting times for a single vacancy diffusing on an FCC lattice with chemical disorder. Thomas and Patala, *Acta Materialia* 196 (2020), 144 to 153, [DOI 10.1016/j.actamat.2020.06.022](https://doi.org/10.1016/j.actamat.2020.06.022), analyzed 2,971 NEB vacancy migrations in CoCrFeMnNi. Their fitted migration-barrier mean and standard deviation were 0.81 and 0.32 eV. They separated the two directions of a transition into symmetric and antisymmetric components with measured standard deviations `sigma_+ = 0.314` eV and `sigma_- = 0.078` eV. They also explain why a distribution of barriers alone is insufficient to represent a rugged energy landscape.

For independent endpoint wells and transition saddles,

```text
E_forward = s - w_A                E_reverse = s - w_B
E_plus    = s - (w_A + w_B)/2      E_minus   = (w_B - w_A)/2
Var(E_plus) = Var(s) + Var(w)/2    Var(E_minus) = Var(w)/2
```

Consequently `sigma_w = sqrt(2) sigma_-`, approximately 0.110 eV, and `sigma_s = sqrt(sigma_+^2 - sigma_-^2)`, approximately 0.304 eV. The resulting untruncated barrier standard deviation is `sqrt(0.110^2 + 0.304^2) = 0.3233` eV. These rounded parameters explain the values in the code. They are statistical surrogates, not energies calculated from individual atomic interactions or a new NEB data set.

## Geometry and chemical state

`apeiron/model.py` stores the FCC lattice as integer triples with even `x + y + z` parity inside a periodic cube of side `2 * cells`. Each conventional cubic cell contributes four FCC sites. The twelve nearest-neighbor displacements are all permutations of `(±1, ±1, 0)`. The minimum size of three cells per axis prevents periodic wrapping from merging distinct nearest neighbors.

There is exactly one vacancy, stored as species code 5. Every other site contains one of Co, Ni, Cr, Fe, Mn. Counts differ by at most one atom; a seeded shuffle assigns them to sites. A KMC hop exchanges the vacancy and the selected neighboring atom in the occupancy map. Thus the chemical configuration evolves, and revisiting a coordinate need not reproduce the same local energy.

## Chemical energy keys

`EnergyLandscape.well_key` reads the twelve species in a fixed displacement order around the vacancy. Absolute coordinates do not enter the key. A dictionary caches one normally distributed well energy for each encountered ordered chemical shell. The cache value is generated by a stable BLAKE2b digest of the seed, energy type, and key, followed by a local seeded Gaussian draw. This makes an identical chemical key reproducible even if first encountered in a different order. A changed shell can obtain a different well. The orientation of the shell relative to the lattice axes is part of the key; rotated shells are not explicitly identified.

`transition_key` describes the moving atom and the union of nearest-neighbor shells around both endpoints. The endpoint occupancies are omitted because the saddle is the bridge state while the atom moves between them. It constructs both endpoint orientations and keeps the lexicographically smaller representation. After an atom-vacancy exchange, the reverse transition has exactly the same key. Therefore both directions use one cached saddle `s_ij = s_ji`. Before drawing a new saddle, the code computes the well at the starting vacancy and the well that the destination vacancy would have after the swap. It rejects a Gaussian saddle candidate below either well. This guarantees nonnegative forward and reverse barriers for the paired states. The number of rejected candidates and total draws are reported.

This environment mapping is a deliberately simple random-energy model. It makes energies depend on local chemistry but does not fit element-specific interaction coefficients or reproduce short-range order. The paper's source alloy was partially ordered; this implementation starts with a shuffled, approximately equiatomic solid solution. Also, the well and saddle keys share chemical input but their Gaussian values are independently seeded. Correlations other than those forced by shared wells and reversible saddles are therefore not calibrated against NEB data.

## One rejection-free KMC event

`KMC.step` performs these operations in order:

1. Read the current vacancy position and its well `w_i`.
2. Enumerate twelve periodic FCC neighbors in the fixed `OFFSETS` order.
3. For each neighbor, construct the transition environment and obtain the symmetric saddle. Calculate `E_ij = s_ij - w_i` and `r_ij = nu exp[-E_ij/(k_B T)]`, with `k_B = 8.617333262e-5` eV/K.
4. Sum the twelve rates to `R` and choose a neighbor using one uniform draw and cumulative rates. Every event executes one swap; there is no rejected KMC proposal. The energy-map rejection sampling is a separate operation performed only when a new saddle key appears.
5. Draw an independent `u` in `(0, 1]`, set `dt = -ln(u)/R`, add it to cumulative time, record the event, and swap the two occupancies.

The common attempt frequency defaults to `1e13` per second and the temperature to 1273 K. Both are run-time parameters. With a common prefactor and symmetric saddle, forward/reverse rate ratios satisfy the expected Boltzmann relation for the two endpoint wells. The test suite checks an immediate reverse transition and its shared saddle.

`events.csv` contains the complete state of the twelve offered jumps at each step. The list columns are JSON arrays embedded in CSV. `waiting_times.csv` is the compact primary result. `summary.json` distinguishes all offered barriers from selected barriers: the latter are rate weighted and should generally have a different distribution. The observed barriers of a walk also need not match a randomly sampled ensemble exactly because the trajectory revisits configurations and preferentially chooses fast routes.

## Million-barrier preflight

`apeiron/analysis.py` draws independent source wells, destination wells, and saddles with the configured Gaussian laws. For each pair, it redraws the saddle until it lies above both endpoint wells. It then collects one million forward barriers by default and reports mean, population standard deviation, minimum, draw count, and rejection fraction. This is an obligatory model check before KMC starts, and it should yield a center near 0.81 eV and spread near 0.32 eV. It is a numerical ensemble experiment, independent of the spatial walk. The finite-sample result varies with seed, and truncation shifts the moments slightly from the untruncated theoretical values.

## Exploratory bit analysis and plots

`apeiron/cli.py` writes one bit per waiting time using `bit = 1` when `dt` exceeds the median of the run. `analysis.py` computes p-values for the monobit frequency, frequency within 128-bit blocks, and runs tests from [NIST SP 800-22 Rev. 1a](https://doi.org/10.6028/NIST.SP.800-22r1a). A runs result is omitted when its frequency prerequisite fails. Short streams under 100 bits are labeled insufficient. These checks are a subset of the suite, not a certification. The in-sample median forces near-perfect bit balance, so the monobit result must not be interpreted as independent evidence of quality. The seeded simulation is pseudorandom; a high p-value does not prove independence, unpredictability, or usable entropy. For stronger randomness research, use independent runs and an extraction method with an explicit entropy estimate and holdout validation.

With `--plot`, Matplotlib writes `diagnostics.png`, showing offered and selected barrier histograms alongside the waiting-time trace. The plot is a descriptive comparison, not a goodness-of-fit test.

## Module map and verification

`main.py` enters the CLI. `apeiron/model.py` owns lattice state, chemical-key energies, and KMC stepping. `apeiron/analysis.py` owns the ensemble preflight and statistical functions. `apeiron/cli.py` parses run parameters and writes outputs. `tests/test_model.py` checks FCC geometry, composition, environment changes, saddle reversal, nonnegative barriers, KMC records and reproducibility, the preflight moments, and basic bit-test behavior.

Use `python -m unittest discover -s tests -v` after a change. For a full demonstration run, use `python main.py --jumps 10000 --plot` and inspect `summary.json` before interpreting the time series.
